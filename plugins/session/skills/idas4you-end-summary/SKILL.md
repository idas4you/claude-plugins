# 끝 정리

이 세션에서 대화한 내용을 정리해 **이 채팅의 마지막 메시지**로 남긴다.

## 순서

1. 정리 직전에 실제 시각을 읽는다. 짐작하지 않는다.

   ```bash
   date '+%Y-%m-%d %H:%M %Z'
   ```

   PowerShell이면 `Get-Date -Format "yyyy-MM-dd HH:mm K"`.

2. 세션 제목을 이 세션의 핵심 작업으로 바꾼다. 세션 제목을 바꾸는 도구가 있을 때만 한다(Claude 데스크톱 앱이면 `mcp__ccd_session_mgmt__set_session_title` — `ToolSearch`의 `select:mcp__ccd_session_mgmt__set_session_title`로 불러온 뒤 `session_id: "self"`로 부른다).
   - 형식: `MM-DD <핵심 작업> — <상태>`. **날짜를 맨 앞에** 둔다(세션 목록에서 날짜로 훑어보기 위해서다). 사용자 개인 안내에 다른 형식이 있으면 그것을 따른다. 사용자가 쓰는 언어로, 50자 안쪽. 상태는 `완료`·`배포 대기`·`검증 대기`·`조사만` 같은 짧은 말. 예: `10-23 relay 도구 결과 이미지 수정 — 배포 대기`
   - 날짜는 1에서 읽은 날짜. 작업이 여럿이면 가장 큰 것 하나만.
   - 도구가 없거나 앱이 승인을 묻다가 거절되면 제목은 그대로 두고, 정리 메시지 끝 줄 바로 위에 `세션 제목: 바꾸지 못함(<이유>) — 제안: <제목>`을 적는다. 바꿨으면 `세션 제목: <제목>`.

3. 아래 형식으로 메시지 하나를 쓴다. 사용자가 쓰는 언어로 쓰고, 명령·경로·커밋 해시는 그대로 둔다.

## 형식

- 맨 위: `정리 시각: <1에서 읽은 날짜 시간>`
- **한 일** — 이 세션에서 한 작업과 그 결과
- **결정** — 사용자와 정한 것, 바뀐 방침
- **바뀐 파일·커밋** — 경로(markdown 링크), 레포·브랜치·커밋 해시, push 여부. 커밋하지 않은 변경은 그렇다고 적는다
- **검증** — 돌린 시험과 결과. 돌리지 않았거나 실패한 것도 그대로 적는다
- **남은 일** — 후속, 미착수, 사용자 결정이 필요한 것. 이 세션에서 `/idas4you-end-check`를 돌렸으면 거기서 처리하지 않고 남긴 것도 옮긴다
- 해당 내용이 없는 절은 빼거나 "없음"으로 적는다
- 끝 줄 바로 위: `세션 제목: …`(2의 결과)
- 맨 끝 줄: `이 세션 작업을 마쳤습니다.`

## 하지 않는 것

- 정리하려고 새 작업(커밋·push·파일 수정·배포)을 하지 않는다. 이미 한 것을 모아 적기만 한다. 세션 제목 변경(2)만 예외다.
- 남은 것을 찾으려고 저장소를 뒤지지 않는다. 그것은 `/idas4you-end-check`가 한다.
- 하지 않은 일을 한 것처럼 쓰지 않는다.
