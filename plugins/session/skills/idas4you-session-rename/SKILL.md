# 세션 제목 바꾸기

지금까지의 대화에서 **핵심 작업 하나**를 골라 세션 제목으로 단다. 하는 일은 그것뿐이다 — 세션 도중에 불러도 되고, 여러 번 불러도 된다.

## 순서

1. 실제 날짜를 읽는다. 짐작하지 않는다.

   ```bash
   date '+%m-%d'
   ```

   PowerShell이면 `Get-Date -Format "MM-dd"`.

2. 제목을 정한다.
   - 형식: `MM-DD <핵심 작업> — <상태>`. **날짜를 맨 앞에** 둔다(세션 목록에서 날짜로 훑어보기 위해서다). 사용자 개인 안내에 다른 형식이 있으면 그것을 따른다.
   - 사용자가 쓰는 언어로, 50자 안쪽.
   - **핵심 작업**은 이 대화에서 가장 큰 일 하나다. 여럿이면 가장 큰 것만 쓰고 나열하지 않는다. "작업", "수정", "질문" 같은 말만으로 끝내지 않고 무엇을 했는지가 보이게 쓴다(`relay 도구 결과 이미지 수정`).
   - **상태**는 지금 어디까지 왔는지를 짧게 — `진행 중`·`완료`·`배포 대기`·`검증 대기`·`조사만`. 대화에 드러난 것으로 정한다. 커밋·push·배포를 했는지 모르면 한 것처럼 쓰지 않는다.
   - 예: `10-23 relay 도구 결과 이미지 수정 — 배포 대기`
   - **인자로 제목을 받았으면 그 말을 그대로 쓴다.** 날짜가 앞에 없으면 붙이고, 상태는 사용자가 적지 않았으면 붙이지 않는다.
   - 비밀값, 사람 이름, 고객 이름은 제목에 넣지 않는다.
   - 이 형식은 `/idas4you-session-summary`와 같다. 고칠 때는 두 곳을 함께 고친다.

3. 제목을 바꾼다. 세션 제목을 바꾸는 도구가 있을 때만 한다(Claude 데스크톱 앱이면 `mcp__ccd_session_mgmt__set_session_title` — `ToolSearch`의 `select:mcp__ccd_session_mgmt__set_session_title`로 불러온 뒤 `session_id: "self"`로 부른다).

4. 한 줄로 알린다.
   - 바꿨으면: `세션 제목: <제목>`
   - 도구가 없거나 앱이 승인을 묻다가 거절되면: `세션 제목: 바꾸지 못함(<이유>) — 제안: <제목>`. CLI라면 `/rename <제목>`을 그대로 칠 수 있게 함께 적는다.

## 하지 않는 일

- 정리 메시지 쓰기, 정리 파일(`~/.claude/session-notes`) 저장. 그것은 `/idas4you-session-summary`가 한다.
- 제목을 정하려고 저장소를 뒤지기(`git log`·`git status`). 대화에 있는 것만으로 정한다.
- 커밋·push·파일 수정.
- 후보를 여러 개 늘어놓고 고르게 하기. 하나를 정해 바꾸고, 마음에 들지 않으면 사용자가 `/idas4you-session-rename <제목>`으로 다시 부른다.
