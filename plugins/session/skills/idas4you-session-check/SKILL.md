# 뒷정리 점검

세션을 끝내기 전에 **치우지 않고 남은 것**을 찾는다. 이 스킬은 먼저 찾아서 보여 주고, 치우는 것은 사용자가 그러라고 한 것만 한다.

## 범위

1. 지금 작업 디렉터리의 저장소. 워크트리 안이면 `git worktree list`로 본 체크아웃과 다른 워크트리까지 본다.
2. 이 세션의 대화에서 건드린 다른 저장소가 있으면 그것도 본다. 대화에 나오지 않은 저장소는 뒤지지 않는다.
3. 저장소 안내 파일(`CLAUDE.md`, `AGENTS.md`)과 사용자 개인 안내에서 기본 브랜치 이름, 브랜치를 남겨 두는 규칙, PR을 쓰는지를 읽는다. 기본 브랜치는 안내가 없으면 `git symbolic-ref refs/remotes/origin/HEAD`로 정한다.

다른 체크아웃은 `cd`하지 않고 `git -C <경로>`로 본다.

## 찾기

먼저 `git fetch --prune`으로 원격 상태를 맞춘다(원격 추적 참조만 바뀐다). 그다음 하나씩 본다.

| 볼 것 | 어떻게 |
|---|---|
| 커밋 안 된 변경 | 워크트리마다 `git status --short`. 추적되지 않는 파일도 포함한다 |
| push 안 된 커밋 | `git for-each-ref --format='%(refname:short) %(upstream:short) %(upstream:track)' refs/heads` — `ahead`인 브랜치와 upstream이 없는 브랜치 |
| 뒤처진 기본 브랜치 | 로컬 기본 브랜치가 `origin/<기본>`보다 `behind`인가 |
| 머지됐는데 남은 로컬 브랜치 | `git branch --merged origin/<기본>` 중 기본 브랜치가 아닌 것 |
| 머지됐는데 남은 원격 브랜치 | `git branch -r --merged origin/<기본>` 중 기본 브랜치·`HEAD`가 아닌 것 |
| 남은 워크트리 | 그 브랜치가 머지됐거나 원격에서 사라진 워크트리. `git worktree prune --dry-run`에 걸리는 것 |
| stash | `git stash list`. stash는 모든 워크트리와 다른 세션이 함께 쓴다 — 이 세션이 만든 것인지 대화로 확인되는 것만 "이 세션 것"으로 적고, 나머지는 있다고만 알린다 |
| 띄워 둔 것 | 이 세션에서 띄운 백그라운드 명령·개발 서버가 아직 도는가(대화에 있는 것만) |
| 설치 플러그인 | 저장소가 플러그인 마켓플레이스일 때만(`.claude-plugin/marketplace.json`이 있다). `claude plugin list`의 버전이 각 `plugin.json`의 `version`보다 낮은가. `claude`를 실행할 수 없으면 "확인하지 못함" |
| 말로 남긴 것 | 이 세션에서 "나중에"·"이따가"라고 하고 하지 않은 일 |

- **스쿼시 머지는 `--merged`로 보이지 않는다.** 머지된 것 같은데 확인되지 않는 브랜치는 "머지 여부 확인하지 못함"으로 적고 지우자고 하지 않는다.
- 이 세션이 만들지 않은 것(다른 세션의 워크트리·브랜치, 예전부터 있던 변경)은 "이 세션 것 아님"으로 따로 묶는다. 대화로 구분되지 않으면 그렇게 적는다.
- 볼 수 없었던 것은 "확인하지 못함"으로 적는다. 본 것처럼 쓰지 않는다.

## 보고

짧게, 이 순서로.

1. **남은 것** — 표로. 칸은 `남은 것 | 어디(저장소·브랜치·경로) | 제안하는 처리`. 처리 칸에는 그대로 칠 수 있는 명령을 적는다. 이 세션 것부터, 그다음 "이 세션 것 아님".
2. **깨끗한 것** — 걸리지 않은 항목을 한 줄로 묶는다.
3. **확인하지 못한 것** — 있으면.
4. 남은 것이 있으면 **어떻게 할지 묻는다**(질문 도구가 있으면 그것으로 — "제안대로 전부" / "골라서" / "그대로 둠"). 남은 것이 없으면 묻지 않고 "남은 것이 없습니다"로 끝낸다.

## 치우기 — 사용자가 그러라고 한 것만

- "제안대로 전부"여도 **되돌리기 어려운 것은 항목을 대고 한 번 더 확인한다**: 원격 브랜치 삭제, 워크트리 삭제, stash 삭제, 기본 브랜치로의 push.
- 커밋 안 된 변경은 **버리지 않는다.** 커밋할지, 그대로 둘지만 묻는다. `git checkout --`·`git reset --hard`·`git clean`은 쓰지 않는다.
- 로컬 브랜치는 `git branch -d`로만 지운다. 거부되면 `-D`로 밀지 않고 그렇다고 보고한다.
- 기본 브랜치를 따라잡을 때는 `git pull --ff-only`. 빨리감기가 안 되면 멈추고 보고한다.
- 지금 이 세션이 들어 있는 워크트리와 그 브랜치는 지우지 않는다. 세션이 끝난 뒤 지울 명령만 적어 준다.
- "이 세션 것 아님"으로 묶은 것은 사용자가 그 항목을 짚어 말했을 때만 손댄다.
- 저장소 안내가 금지한 것(기본 브랜치 직접 push 등)은 하지 않고 안내를 댄다.
- 치운 뒤 걸렸던 항목을 다시 확인해 결과를 한 줄씩 적는다.

마지막 줄에 "세션 내용 정리는 `/idas4you-session-summary`"를 남긴다. 직접 부르지는 않는다.

## 하지 않는 일

- 묻지 않고 지우기·push·커밋.
- 코드 수정, 머지, 배포.
- 대화에 나오지 않은 저장소 뒤지기.
- 비밀값을 보고에 옮기기. 추적되지 않는 `.env` 같은 파일은 이름만 적는다.
